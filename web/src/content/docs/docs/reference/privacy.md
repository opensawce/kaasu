The full policy is in [PRIVACY.md](https://github.com/opensawce/kaasu/blob/main/PRIVACY.md). In short: a self-hosted Kaasu keeps everything on your machine, payer identifiers are masked, and AI provider integration is not available in this version, so nothing is sent to an AI provider. If it is added later it will be off by default and send masked text only.
