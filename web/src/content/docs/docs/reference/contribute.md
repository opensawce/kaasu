## Edit the docs

1. Open the page and choose **Edit page**, or edit the file in `web/src/content/docs/docs/`.
2. Add a new page by creating a `.md` file in the right folder. It joins the sidebar by itself. Use `sidebar: order: n` in the front matter to place it.
3. Preview with `cd web && npm install && npm run dev`.
4. Open a pull request.

## Style

Write for a shop owner. Say what it does for them, not how it is built. No emojis, no em dashes.
